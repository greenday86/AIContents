# LEGO F1 챔피언스

브라우저에서 즐기는 간단한 2D 탑다운 레고 스타일 F1 레이싱 게임입니다. 플레이어는 레고 브릭으로 구현된 머신을 조종하며, AI 드라이버들과 1랩 스프린트 경쟁을 펼칩니다.

## 기획 핵심

- **테마**: 레고 브릭 질감을 가진 트랙과 차량, 밝은 색상 대비를 통해 블록 완구 느낌을 강조했습니다.
- **조작**: 방향키를 통해 좌우 이동 및 가속/감속, `R` 키로 레이스를 리셋할 수 있습니다.
- **페이스**: 1랩 3200m 길이의 직선형 서킷, 상단 HUD를 통해 진행률과 현재 순위를 직관적으로 확인할 수 있습니다.
- **경쟁 요소**: 4명의 AI 드라이버가 각기 다른 기본 속도를 가지고 주행하며, 플레이어와 근접하면 차선 변경을 시도합니다.

## 실행 방법

1. 저장소 루트에서 `lego-f1-racer/index.html` 파일을 브라우저로 엽니다.
2. 브라우저에서 방향키와 `R` 키를 사용하여 레이스를 즐길 수 있습니다.

## 향후 확장 아이디어

- 다중 랩과 피트 스톱 전략 요소 추가
- 모바일 터치 입력 대응
- 코너가 존재하는 코스와 오브젝트(커브, 장애물) 배치
- 사운드 이펙트 및 배경 음악
- 레이스 후 리플레이 혹은 하이라이트 저장

즐거운 레고 F1 레이싱을 즐겨보세요!
