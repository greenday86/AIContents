## 🎮 LEGO F1 챔피언스
웹브라우저에서 실행할 수 있는 간단한 레고 스타일 F1 레이싱 게임 데모입니다. 플레이어는 레고 브릭으로 구현된 머신을 조종하며, AI 드라이버들과 1랩 스프린트 경쟁을 펼칩니다.

### 게임 개요

- **장르**: 2D 탑다운 레이싱 게임
- **테마**: 레고 브릭 스타일의 F1 레이싱
- **플랫폼**: 웹 브라우저 (HTML5 Canvas)
- **기술 스택**: 순수 JavaScript (프레임워크 없음)

### 기획 핵심

- **테마**: 레고 브릭 질감을 가진 트랙과 차량, 밝은 색상 대비를 통해 블록 완구 느낌을 강조했습니다.
- **조작**: 방향키를 통해 좌우 이동 및 가속/감속, `R` 키로 레이스를 리셋할 수 있습니다.
- **페이스**: 1랩 5200 단위 길이의 S자형 서킷을 레고 브릭으로 쌓아 올린 느낌으로 표현했으며, 진행률 HUD로 남은 거리를 확인할 수 있습니다.
- **경쟁 요소**: 4명의 AI 드라이버가 각기 다른 기본 속도와 라인 공략 패턴을 가지고 주행하며, 플레이어와 근접하면 차선 변경을 시도합니다.
- **비주얼**: 각 차량은 고유 컬러와 넘버링을 가진 레고 브릭 디자인을 적용했고, 관중석과 피트월 배너 등 배경 장식을 더해 현장감을 높였습니다.

### 실행 방법

1. `lego-f1-racer/index.html` 파일을 브라우저로 엽니다.
2. 방향키와 `R` 키를 사용하여 레이스를 즐깁니다.

### 조작 방법

- **↑** : 가속
- **↓** : 감속
- **← / →** : 좌우 차선 변경
- **R** : 레이스 리셋
- **Space** : 터보 사용 (게이지 가득 시)

## 💻 코드 구조 설명

### `lego-f1-racer/index.html`
게임의 메인 HTML 구조를 정의합니다.
- 사이드바: 레이스 정보, 조작 방법, 계기판 (속도, 라운드, 포지션, 터보 게이지)
- 캔버스 영역: 실제 게임이 렌더링되는 800x600 픽셀 Canvas
- 카운트다운 및 완주 배너 UI

### `lego-f1-racer/game.js` (핵심 게임 로직)

#### 주요 상수 및 설정
- `TRACK_LENGTH`: 트랙 길이 (5200 단위)
- `LANE_COUNT`: 차선 개수 (4개)
- `BOOST_MAX`: 터보 최대 게이지 (100)
- `HAZARD_SLOW_FACTOR`: 위험물 감속 계수

#### 핵심 함수 구조

1. **초기화 함수**
   - `initializePlayers()`: 플레이어와 AI 드라이버 초기화
   - `setupTrackEvents()`: 트랙의 수집품(브릭)과 위험물 배치
   - `ensureElements()`: DOM 요소 검증 및 캔버스 컨텍스트 설정

2. **입력 처리**
   - `handleInput()`: 키보드 입력 감지 및 상태 업데이트
   - `handleInputFrame()`: 플레이어 차량의 물리 계산 (가속, 감속, 차선 이동)
   - `tryActivateBoost()`: 터보 활성화 처리

3. **AI 시스템**
   - `updateAI()`: AI 드라이버의 자동 주행 로직
   - 플레이어와 근접 시 차선 변경 시도
   - 각 AI마다 다른 기본 속도와 패턴

4. **트랙 이벤트**
   - `checkCollectibles()`: 브릭 수집품 획득 처리 (터보 게이지 충전)
   - `checkHazards()`: 위험물 충돌 처리 (속도 감소)
   - `processTrackEvents()`: 트랙 이벤트 통합 처리

5. **렌더링 시스템**
   - `drawTrack()`: 원근감을 활용한 3D 스타일 트랙 렌더링
   - `drawCars()`: 레고 브릭 스타일의 차량 그리기
   - `drawCollectibles()`: 수집품 렌더링
   - `drawHazards()`: 위험물 렌더링
   - `drawBackdropLayers()`: 배경 (하늘, 도시, 관중석) 그리기

6. **게임 루프**
   - `update()`: 매 프레임 게임 상태 업데이트
   - `render()`: 매 프레임 화면 렌더링
   - `gameLoop()`: `requestAnimationFrame` 기반 게임 루프

7. **UI 업데이트**
   - `updateUI()`: 속도, 순위, 터보 게이지 등 실시간 UI 업데이트
   - `triggerMoment()`: 게임 중 이벤트 알림 (수집, 위험, 추격 등)
   - `showFinishBanner()`: 완주 시 결과 배너 표시

#### 게임 메커니즘

- **물리 시스템**: 마찰, 가속, 감속을 고려한 속도 계산
- **터보 시스템**: 브릭 수집으로 게이지 충전 → Space 키로 발동 → 속도 35% 증가
- **위험물 시스템**: 특정 구간의 위험물 충돌 시 일정 시간 감속
- **트랙 커브**: `trackSegments` 배열로 정의된 S자형 커브 경로
- **충돌 감지**: 차량 간 거리 기반 충돌 처리

게임 UI의 스타일을 정의합니다.

## 🎯 게임 특징

### 비주얼
- 레고 브릭 스타일의 차량 디자인 (각 차량마다 고유 색상과 번호)
- 원근감을 활용한 3D 스타일 트랙 렌더링
- 관중석, 피트월 배너 등 배경 장식
- 터보 발동 시 시각적 이펙트

### 게임플레이
- 4명의 AI 드라이버와 경쟁
- 18개의 브릭 수집품으로 터보 충전
- 5개의 위험물 구간 (오일, 모래, 브릭 파편 등)
- 실시간 순위 및 거리 표시
- 근접 경쟁 시 알림 시스템

### 기술적 특징
- 프레임워크 없이 순수 JavaScript로 구현
- Canvas 2D API를 활용한 렌더링

- 객체 지향적 함수 구조
